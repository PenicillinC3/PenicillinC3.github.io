从 Windows Terminal 到 macOS 的 iTerm，能统一的地方尽量统一。

## 固定搭配

- 终端：Windows Terminal / iTerm2，背景开毛玻璃半透明；
- Shell：zsh + starship 提示符；
- 字体：等宽字体里找支持中文的，避免中文回退到宋体。

> 提示符宁简勿繁：显示「目录 + 分支」就够了。

## 配置放仓库

把 dotfiles 放进 git 仓库是维护终端配置最省心的方式——重装系统后一条命令拉回来。
